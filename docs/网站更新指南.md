# Leo Xiang Art 网站更新指南

本次工作目录：`/Users/mac/Documents/ChatGPT/个人网站/website`。原目录未修改。

以后只需把照片放进指定文件夹，然后把下面任一段复制给 Codex，并补上知道的信息。不知道的留空；不需要自己改网页或 JSON。

## 1. 新增观鸟活动

照片放入 `incoming/events/`，每次活动可以建子文件夹。

> 请新增观鸟活动。日期：；地点：；路线：；组织者：；主要鸟种（我已确认）：；参加人数：；活动介绍：；总结：；照片文件夹：。请整理英文草稿，未知信息留空，用开发分支生成预览，未经确认不要正式发布。

数据模板：`content/templates/event.json`。由 Codex 将完整条目添加至 `content/events.json`。照片数组格式为 `[{"image":"incoming/events/文件.jpg","alt":"准确的英文图片说明"}]`。活动按日期从新到旧展示；缺少日期的排在最后。

## 2. 批量增加摄影作品

照片放入 `incoming/photography/`。

> 请批量增加摄影作品。照片文件名与标题对应：；已确认英文鸟名和学名：；拍摄日期：；地点：；主题分类：；简短说明：。没有确认的鸟种不要识别或填写。请提供英文草稿与预览，不正式发布。

模板：`content/templates/photograph.json`；数据：`content/photography.json`。可一次添加多张，每张一条记录。现有摄影作品保留旧标题，但鸟名、学名、拍摄日期和地点保持空白。主题可用 Coastal、Wetlands 等你确认的类别。点击图片或键盘 Enter 放大，Esc 关闭。

## 3. 更新艺术商品

新作品图片放入 `incoming/art/`。

> 请新增或更新艺术作品。作品名称：；图片：；创作说明：；分类（design/painting）：；Redbubble 链接：；Etsy 链接：；需要删除的旧链接：。请保留其他内容，不抓取价格和折扣，生成预览，不正式发布。

模板：`content/templates/artwork.json`；数据：`content/art.json`。商品链接结构为 `[{"url":"https://...redbubble.com/..."},{"url":"https://www.etsy.com/..."}]`，删除链接后从对应数组移除即可。没有准确的作品购买地址时不自动拼接；现有 Redbubble 总店链接单独保留。

## 审核与发布

Codex 会把新增内容加入对应栏目；只有填写真实 `updatedAt` 日期的已公开条目进入首页 Latest Updates。旧内容迁移不虚构更新日期，因此初始 Latest Updates 显示提示语。

检查英文、日期、鸟名、照片版权和购买链接。确认无误后明确说“批准将这个预览版本发布到正式网站”。此前只在开发分支和预览中工作。

技术维护：Node 24 LTS，首次运行 `npm ci`，之后 `npm run build` → `npm run check` → `npm run preview`，打开 http://127.0.0.1:4173。修改数据后重新构建即可。Vercel 沿用 `npm run build` 和 `dist`，自动安装 sharp 图片处理依赖。原照片仅供构建，不随 incoming 目录上传到网页；生成图片无 EXIF 元数据。

若启用 GitHub 自动预览，开发分支推送后在 Vercel 项目 Deployments 中打开对应 Preview；不要点击 Promote to Production。未核实 Vercel Production Branch 前不要盲目推送。
